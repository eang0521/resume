\section*{Projects}
\textbf{Quick Draw} --- Built a full-stack tournament bracket tool with Next.js, TypeScript, and Supabase to organize and run single-elimination, double-elimination, round robin, and swiss format competitions.\\[4pt]
\textbf{NBA Game Simulator} --- Built a Python pipeline that scrapes real NBA player and team stats spanning the last 40 seasons to drive a dice-based basketball game simulation, capable of simulating both individual games and full seasons with play-by-play logs and final box scores.
