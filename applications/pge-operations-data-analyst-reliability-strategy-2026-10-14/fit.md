## Gaps and how to address them honestly
- **2-year minimum:** Do not inflate. The letter leaves it out; the resume lists every role truthfully. Your argument is "equivalent work experience" plus the four internships/projects. Expect an ATS or recruiter screen to be the main risk; a referral or direct message to the hiring manager could help (you would send it yourself).
- **Oracle/Business Objects, SAS, UNIX, VBA:** All are "desired," not required. In an interview, say you are strong in standard SQL and Python and quick to pick up new tools. Optional prep: a free Oracle SQL / SAS / shell tutorial, which would let you claim them honestly later.
- **Utility domain:** Read PG&E's public reliability material (SAIDI/SAIFI-type metrics) before an interview so you can speak about the problem even without direct experience.
- **Data governance:** Frame documentation and validation habits from the pipeline work if asked, without claiming formal governance experience.
